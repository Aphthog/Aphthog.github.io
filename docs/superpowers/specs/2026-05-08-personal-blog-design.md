# Camille 个人博客 — UI/UX 设计方案

## 概述

基于 Hexo + NexT 的个人博客，重新设计 UI。以**温暖暗色调**为基调，内容优先，分类驱动浏览。目标：让博客既有个人品牌感，又提供专注的阅读体验。

## 设计定位

| 维度 | 选择 |
|------|------|
| **风格** | 温暖暗调 + 内容优先，偏个人创作感 |
| **配色** | 炭火琥珀（深暖棕底 + 琥珀金 accent + 鼠尾草绿点缀） |
| **字体** | 标题：Crimson Pro（衬线，温暖优雅）/ 正文：Nunito（圆润清晰） |
| **中文** | Noto Sans SC / PingFang SC 系统字体栈 |
| **布局** | 分类筛选 → 纯文字文章流，max-width: 720px |

## 配色系统

| Token | Hex | 用途 |
|-------|-----|------|
| `--bg` | `#1a1410` | 页面背景，深暖棕黑 |
| `--surface` | `#221a14` | 卡片/区域背景 |
| `--accent` | `#c4843e` | 琥珀金 accent，链接/按钮/高亮 |
| `--accent-hover` | `#d4955e` | accent hover 态 |
| `--text-primary` | `#f0e8de` | 主文字色，暖白 |
| `--text-secondary` | `#a09080` | 副文字色，暖灰 |
| `--text-muted` | `#7a6b5c` | 弱化文字 |
| `--border` | `#2d241e` | 分割线/边框 |
| `--muted` | `#1f1812` | 极弱背景 |
| `--accent-secondary` | `#8a9a7a` | 鼠尾草绿点缀 |
| `--error` | `#c4675a` | 错误/删除 |

## 字体系统

- **标题**: `Crimson Pro`, Georgia, `Noto Serif SC`, serif — 衬线体，增加温暖感和文字质感
- **正文**: `Nunito`, `Noto Sans SC`, `PingFang SC`, `Microsoft YaHei`, sans-serif — 圆润清晰，中英文混排优化
- **代码**: `JetBrains Mono`, `Fira Code`, monospace — 等宽字体
- **字号层级**: 12 / 13 / 14 / 15 / 17 / 20 / 24 / 28 / 32 px
- **正文行高**: 1.75
- **最大行宽**: 680px（文章正文）

## 页面布局

### 首页（Home）
1. **导航栏**: 站点名 `Camille`（左）+ 首页 / 归档 / 关于（右）
2. **分类选择区**: 三个分类按钮（技术笔记 / 摄影 / 随笔），选中态 = 实心琥珀金底，未选中 = 透明描边
3. **文章列表**: 选中分类后展示该分类文章流，纯文字无边框
   - 每项：日期(左) | 标题(中) | 简短摘要(右)
   - 分割线分隔
4. **分页**: 简约数字分页

### 文章页（Post）
1. 文章头：分类标签 + 日期
2. 文章标题：28px Crimson Pro 衬线体
3. 摘要引用块：左侧竖线分隔
4. 正文：15px，最大 680px
5. 代码块：`#0f0c09` 深底 + 琥珀金关键字高亮
6. 标签区：文章底部圆角标签

### 响应式断点
- 375px（手机小屏）
- 768px（平板）
- 1024px（桌面窄）
- 1440px（桌面宽）

## 交互规范

| 元素 | 行为 |
|------|------|
| 分类按钮 | hover: 边框亮起; 选中: 实心accent bg |
| 文章行 | hover: color 微变, translateX(4px) |
| 链接 | color: accent, hover: accent-hover |
| 过渡 | 所有交互 200ms ease |
| 触摸目标 | 最小 44×44px |

## 设计规则

- **间距系统**: 8px 网格（4/8/16/24/32/48/64px）
- **圆角**: 按钮 100px · 区域 14px · 代码块 10px · 标签 100px
- **分割线**: `border-bottom: 1px solid #1f1a14`（文章列表项之间）
- **图标**: 使用文本符号代替图标，保持轻量

## 已排除（YAGNI）

- 评论系统（后续可接入 Gitalk/Waline）
- 站内搜索
- 访问统计
- 夜间/日间模式切换（始终保持暗色）
- 图片画廊/灯箱

## 实现优先级

1. **P0** — 首页替换（分类筛选 + 文章流）, 解决全屏黑边问题
2. **P1** — 文章详情页样式（字体/代码块/标签）
3. **P2** — 过渡动画 + 微交互
4. **P3** — 归档页 / 关于页统一样式
